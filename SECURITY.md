# Security

Never paste tokens, customer records, private project files, or sensitive logs
into public issues. Use GitHub's **Security > Report a vulnerability** when enabled
for this repository. If unavailable, open a minimal issue requesting a private
contact route without including vulnerability details or sensitive information.

Include the suite version, affected setup step, a synthetic reproduction, and
the expected boundary. Report unintended overwrite, permission expansion,
instruction conflicts, or unsafe export behavior.

The suite supplies instructions, not a security sandbox. Codex client and host
permissions remain authoritative. Review staged changes before accepting an
installation. A checksum detects changed bytes; it does not prove a source is
trustworthy.
